Recommendation

Move to Ghost when James hits 200 paid subscribers.

Ghost is purpose-built for exactly what James needs: a serious editorial voice with paid memberships, a proper newsletter, and a public API so the website can verify subscriber status and unlock content. It is used by serious independent publishers — The Browser, Stratechery, and others at James's level.

The migration is straightforward: export subscribers from Substack as a CSV, import to Ghost, redirect the Substack domain, and update the subscribe forms. Free subscribers move instantly. Paid subscribers need to re-enter their card details once — with a well-crafted email, conversion rate is typically 80–90%.

Now (0–200 paid subs)

Stay on Substack. Free subscribe now inline on the website. Paid clicks through to Substack. Don't migrate yet — the fee savings don't justify the migration effort at this scale.

Phase 2 (200+ paid subs)

Migrate to Ghost. 3–5 day project. Free subs imported automatically. Paid subs re-subscribe via a clear "we've moved" email. Saving: ~£100/mo at this scale, rising fast.

Phase 3 (500+ paid subs)

Ghost API connected to ww2andallthat.com. Paid members get full article access on-site. Substack is gone. James owns his audience completely.

What a Ghost Migration Involves

What we do (CI)

  • Set up Ghost instance (Ghost.org managed hosting — no server to maintain)
  • Import subscriber CSV from Substack
  • Recreate James's newsletter template in Ghost
  • Connect Ghost API to ww2andallthat.com for paid access verification
  • Set up Stripe in Ghost for recurring billing
  • Redirect james1940.substack.com to ww2andallthat.com
  • Test end-to-end: subscribe, pay, access gated content on site

What Paul does

  • Export subscriber list from Substack (Settings > Subscribers > Export)
  • Approve the Ghost newsletter template design
  • Send the "we've moved" email to paid subscribers asking them to re-subscribe
  • Create Stripe account (if not already done)
  • Approve the new subscribe flow on ww2andallthat.com
